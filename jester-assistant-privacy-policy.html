Jester Assistant Privacy Policy

Effective date: May 15, 2026

Developer: Round Table Arts / SyntaxTerror404

Jester Assistant is a companion app that lets a user connect an Android device to their own Jester Assistant desktop software. The app is designed for user-directed commands such as opening apps, opening websites, placing calls, sending SMS messages, and looking up contacts after the user grants the required Android permissions.

This policy explains what information the app can access, how it is used, and how users can control or remove it.

Information We Access

Jester Assistant may access the following information only when the related feature is enabled or used:

  • Contacts: Used to match spoken or typed commands such as “call Dad” or “text Sue.”
  • SMS messages: Used to compose and send text messages only when the user gives a command to do so.
  • Phone/call functions: Used to place calls only when the user gives a command to do so.
  • Installed apps: Used to find and open apps by the name visible to the user.
  • Notifications and foreground service status: Used to show that the Jester bridge connection is active and to keep the connection available while enabled.
  • Device identifier generated by the app: Used so the desktop bridge can approve or deny a specific phone or tablet.
  • Bridge URL and pairing token: Used to connect securely to the user’s own Jester desktop bridge.

How Information Is Used

The app uses information to perform user-requested actions and maintain the connection between the Android device and the user’s paired desktop computer. Examples include resolving a contact name, opening an app, opening a URL, sending a text message, or placing a call.

The app does not use accessed information for advertising, profiling, or selling user data.

Data Sharing

Jester Assistant does not sell personal information. The app may send command results and user-requested data, such as a selected contact match or command status, to the user’s own paired Jester desktop bridge. This transfer is initiated by the user’s setup and pairing process.

Data is not shared with advertising networks or third-party analytics services by this app.

Local Network and Bridge Connection

The Android app connects to the Jester desktop bridge using a WebSocket URL entered by the user or found through local network discovery. The bridge requires a pairing token and desktop approval before commands are accepted.

Users should only connect to trusted desktop bridge URLs, such as their own local network address or trusted private network address.

Security

Jester Assistant uses a pairing token and a PC-side device approval process to reduce unauthorized access. Users should keep pairing tokens private and approve only devices they recognize.

Local WebSocket connections may use a local network address. Users who need off-Wi-Fi access should use a trusted private network such as Tailscale or another secure private network setup.

Permissions

The app requests Android permissions only for features that need them. If a permission is denied, the related feature may not work, and the app will show a message explaining what is needed.

Users can change permissions at any time in Android Settings.

Data Retention and Deletion

Bridge settings, pairing status, and the generated device identifier may be stored on the Android device to make reconnecting easier. Users can remove this data by using app controls where available, clearing app storage, or uninstalling the app.

Trusted or denied device records may also be stored on the paired desktop computer. These can be cleared from the Jester desktop software using the mobile device trust commands.

Children’s Privacy

Jester Assistant is not intended for children under 13. The app is intended for users who can understand and manage device permissions, phone commands, and desktop pairing.

Changes to This Policy

This privacy policy may be updated as Jester Assistant changes. The updated effective date will be shown at the top of this page.
